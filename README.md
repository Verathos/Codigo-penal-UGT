> — Edição Consolidada 2024–2026

---

## 📜 Sobre

Este repositório contém a legislação oficial e vinculante da **República Federativa da UGT**, promulgada ao longo dos anos em resposta a eventos cujos nomes não serão mencionados para preservar a saúde emocional dos envolvidos.

O documento está disponível como página web estática, pronta para GitHub Pages.

## 🚀 Como publicar no GitHub Pages

1. Crie um repositório no GitHub (ex: `ugt-codigo-penal`)
2. Faça upload do arquivo `index.html`
3. Vá em **Settings → Pages**
4. Em *Source*, selecione **Deploy from a branch → main → / (root)**
5. Clique em **Save**
6. Aguarde ~1 minuto e acesse `https://seuusuario.github.io/ugt-codigo-penal/`
